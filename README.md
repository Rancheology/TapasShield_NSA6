## 1. System Overview

TapasShield is a zero-trust industrial IIoT safety, anti-falsification ledger, and predictive maintenance platform designed to eliminate boiler telemetry tampering, prevent catastrophic boiler explosions, and safeguard MSME plants from statutory non-compliance and fuel waste.

It directly solves the core mandate of the **India EODB Grand Challenge**:
> *"Uploads boiler operational telemetry to a secure online register accessible both by the business and the inspecting departments of the State and the Central Government."*

### Key Architecture Components:
1. **Thermodynamic Digital Twin (`backend/boiler_twin.py`)**: Models an industrial fire-tube boiler rated at MAWP = 15.0 bar using exact IAPWS-IF97 steam tables. Translates physical states to industrial $4\text{–}20\text{ mA}$ currents and ADC counts: Channels 1–4 to 16-bit ADS1115 ADC counts and Channel 5 (`AT-101`) to ESP32-S3 12-bit SAR ADC counts over $150.0\,\Omega$ precision shunt resistors.
2. **Edge SIL Node (`backend/edge_sil_node.py`)**: Emulates hardware security element (ATECC608B). Reconstructs engineering units from ADC counts, executes 3 edge security checks (wire-cut $<3.6\text{ mA}$, thermodynamic cross-correlation $|T_{\text{steam}} - T_{\text{sat}}| > 5.0^\circ\text{C}$ or zero-variance clamp, and IBR overpressure/low-water checks), signs canonical RFC 8785 payloads using ECDSA NIST P-256 (`secp256r1`), and maintains a SHA-256 hash chain.
3. **Statutory Inspector Ledger & EODB Engine (`backend/inspector_ledger.py`)**: Immutable zero-trust registry verifying SHA-256 hash chaining and ECDSA digital signatures on every packet. Features:
   - Full forensic audit scanning to pinpoint historical database tampering (`GET /api/ledger/audit`).
   - Multi-State National Industrial Cluster Grid across TN, GJ, MH, and PB (`GET /api/eodb/national-registry`).
   - Dynamically generated and cryptographically signed IBR Form-VI Digital Use Certificates (`GET /api/eodb/certificate`) that auto-renew when compliant and instantly revoke in crimson upon safety or tamper breach.
4. **Predictive Maintenance Engine (`backend/predictive_engine.py`)**: Calculates real-time indirect boiler efficiency per IS 8753 (Siegert formula), fuel financial waste in ₹/hr and ₹/year, $\text{CaCO}_3$ scale thickness, and Remaining Useful Life (RUL) until mandatory statutory descaling.
5. **ESP32-S3 Hardware Firmware (`firmware/src/main.cpp`)**: Production-ready C++ firmware using `mbedtls` ECDSA P-256 and SHA-256, Wokwi simulation configuration (`diagram.json`, `wokwi.toml`), and complete 42-component BOM & pin-to-pin netlist (`hardware/KICAD_BOM_AND_NETLIST.md`).
6. **KiCad 8 PCB & ISO Schematic Blueprint (`hardware/`)**: Complete KiCad 8 board (`tapasshield_edge.kicad_pcb`, 120mm x 90mm) with 16 custom self-contained VRML 2.0 3D models (`hardware/3d_models/`), strict 45°/90° Manhattan routing, verified KiCad 8 CLI DRC (0 airwires, 0 shorts, 0 collisions, 0 clearances), and publication-grade ISO blueprint (`tapasshield_schematic_blueprint.svg`) generated by `hardware/generate_kicad_board.py`.
7. **Official NSA 6.0 15-Slide Presentation Deck (`presentation/`)**: Programmatically generated 16:9 widescreen presentation (`TapasShield_NSA6_Final_Deck.pdf`, `TapasShield_NSA6_Final_Deck.pptx`, and `TapasShield_Visual_User_Guide.pdf`) built via headless Playwright engine (`presentation/build_dynamic_deck.py`). Features 10 executive business/architecture slides + 5 image-first visual user guides (360° PCB callouts, physical wiring & LTE router architecture, full-screen business SCADA portal, full-screen inspector e-Register, and 4-step quickstart with GitHub QR).
8. **Quint-Cockpit Industrial SCADA & Shared Online Register UI (`frontend/`)**: Vite + React + Tailwind CSS dashboard featuring persistent NSA 6.0 Jury Control Bar with 5 interactive fault scenarios and one-click stakeholder switching:
   - **Dual Split-Screen Live Sync (HERO VIEW)**: MSME Plant Cockpit on left and State & Central Govt Inspector e-Register on right updating simultaneously over WebSockets.
   - **Business Portal (MSME Operator)**: Animated SVG P&ID digital twin, live 5-channel 4–20 mA gauges, IS 8753 efficiency, ₹/hr fuel loss ticker, and scale RUL countdown.
   - **State & Central Govt Inspector Portal**: Central Govt (DPIIT) National Industrial Cluster Grid, State Inspector forensic blockchain ledger, and live IBR Form-VI Digital Certificate modal with instant tamper revocation.
   - **Hardware CAD & Netlist View**: Interactive PCB viewer with layer controls (`F.Cu`, `B.Cu`, `F.SilkS`), blueprint viewer, and searchable 42-item BOM.
   - **NSA 6.0 Pitch Deck View**: Full interactive 16:9 slide player with keyboard navigation, thumbnail strip, `.PPTX` and `.PDF` download buttons, and print export.

## 2. Verification Commands


```bash
conda run -n tapasshield-nsa6 python presentation/build_dynamic_deck.py
```

```bash
conda run -n tapasshield-nsa6 python hardware/generate_kicad_board.py
kicad-cli pcb drc hardware/tapasshield_edge.kicad_pcb --format json --output hardware/drc_report.json
```

```bash
cd firmware
conda run -n tapasshield-nsa6 pio run
```

### React Frontend Production Build (Vite + TypeScript)
```bash
cd frontend
npm run build
```

## 3. Launching the Live System

### Backend Server (FastAPI + WebSocket + Static UI)
```bash
conda run -n tapasshield-nsa6 uvicorn backend.main:app --host 0.0.0.0 --port 8000
```
Navigate to `http://localhost:8000` to interact with the full quint-cockpit dashboard and jury controls.

### Frontend Development Server (Hot-Reload Mode)
```bash
cd frontend
npm run dev
```
Navigate to `http://localhost:5173`.

## 4. Quick Start (Clone & Run Anywhere)

Run the complete TapasShield stack locally (requires Python 3.10+ and Node.js 18+):

```bash
git clone https://github.com/Rancheology/TapasShield_NSA6.git
cd TapasShield_NSA6
pip install -r requirements.txt
playwright install chromium
cd frontend && npm install && npm run build && cd ..
uvicorn backend.main:app --host 0.0.0.0 --port 8000
```

Open http://localhost:8000 in your browser to access the live Dual-Access Online Register.

### Run Verification Test Suite
```bash
pytest tests/
```
